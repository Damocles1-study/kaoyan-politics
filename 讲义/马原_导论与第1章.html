0. 导论：马克思主义是什么

考点骨架
  • 创立者：马克思、恩格斯；三大组成部分：马克思主义哲学、政治经济学、科学社会主义。
  • 产生条件三件套：① 经济社会根源——资本主义大工业 ＋ 无产阶级登上历史舞台（法国里昂工人起义、英国宪章运动、德国西里西亚纺织工人起义）；② 直接理论来源——德国古典哲学、英国古典政治经济学、英法空想社会主义；③ 自然科学前提——细胞学说、能量守恒与转化定律、生物进化论。
  • 鲜明特征：科学性、人民性、实践性、发展性；一句话概括＝科学性与革命性的统一。
  • 当代价值：观察当代世界变化的认识工具 · 指引当代中国发展的行动指南 · 引领人类社会进步的科学真理。
把马克思主义想成一道菜：经济社会根源是「饿了」（工人运动需要理论），理论来源是「三种食材」（德国哲学、英国经济学、英法空想社会主义），自然科学是「灶台」（三大发现提供了物质世界普遍联系的证据）。题目问「食材」你却选「灶台」，就是最经典的掉包。
人民性是马克思主义的本质属性；实践性是马克思主义理论区别于其他理论的根本特征；发展性体现马克思主义与时俱进的理论品质。
马恩著作时间轴——选择题最爱考「第一次」：
1844《德法年鉴》：完成两个转变（唯心→唯物，革命民主主义→共产主义）
1844《神圣家族》：第一次合作
1845《关于费尔巴哈的提纲》：包含新世界观天才萌芽的第一个文件
1845–1846《德意志意识形态》：首次系统阐述历史唯物主义基本观点
1848《共产党宣言》：第一个纲领性文献，标志马克思主义公开问世
1867《资本论》第一卷：剩余价值学说 · 1876–1878《反杜林论》：全面阐述马克思主义理论体系
口诀：44 转身（德法年鉴）认亲（神圣家族），45 萌芽（提纲）立史观（德意志），48 发宣言。
「马克思主义提供了解决一切问题的现成答案 / 现成方案」——永远错。马克思主义是行动指南，不是教条。
书上说「马克思主义的基本特征是科学性与革命性的统一」→ 潜台词：人民性、实践性、发展性在指导革命的过程中集中体现为革命性，所以四个特征能压缩成两个词 → 能考：单选让你从「人民性与实践性的统一」「科学性与实践性的统一」里挑，只认 科学性 ＋ 革命性。

1. 哲学基本问题

考点骨架：哲学基本问题＝思维和存在的关系问题（＝意识和物质的关系问题），包括两方面：
  1. 谁是第一性（世界的本原是物质还是精神）→ 划分唯物主义 / 唯心主义的唯一标准；
  2. 思维能否正确认识存在（同一性问题）→ 划分可知论 / 不可知论。
第一问是「谁生了谁」：物质生意识（唯物）还是意识生物质（唯心）？第二问是「儿子能不能看懂爹」：人能不能认识世界（可知）还是永远隔一层（不可知，休谟、康德）？
唯心主义两种形态（多选常考「下列属于××唯心主义的有」）
类型认定的本原招牌句
主观唯心主义人的主观精神（心、我、感觉）心外无物 · 存在就是被感知 · 万物皆备于我 · 物是感觉的复合 · 世界是观念的集合 · 心诚则灵
客观唯心主义人以外的「客观精神」理在事先 · 绝对观念外化为世界 · 上帝创造世界 · 天不变道亦不变（董仲舒，兼形而上学）
看主语：「心 / 我 / 感觉 / 观念」→ 主观唯心；「理 / 天 / 上帝 / 绝对精神」→ 客观唯心。一秒判断。
「物质和意识的对立是绝对的」错。列宁：这种对立只在「何者第一性」的范围内才有绝对意义，超出这个范围就是相对的——否则就会滑向二元论。

2. 物质观：世界是什么做的

唯物主义物质观的三种形态
形态说物质是什么缺陷
古代朴素唯物主义水、火、气、五行、原子等具体物质把物质归结为具体物质形态，是直观猜测
近代形而上学唯物主义原子（物质的最小单位）① 把特殊形态当物质一般 ② 机械性、形而上学性 ③ 历史观上唯心（割裂自然与社会的物质统一性）
辩证唯物主义不依赖于人的意识、并能为人的意识所反映的客观实在—
物质的唯一特性是客观实在性。
哲学里的「物质」不是指桌子、原子、电子这些具体的东西，而是它们共同的那一点——「不管你信不信，它都在那儿」。所以科学发现了夸克、暗物质、量子纠缠，都推翻不了哲学的物质概念：它们照样不以人的意志为转移。
书上说「马克思主义物质观体现了唯物论和辩证法的统一」→ 潜台词：它既划清了与唯心主义的界限（物质第一性），又划清了与形而上学唯物主义的界限（不把物质等同于某种具体形态）→ 能考：多选「马克思主义物质观的意义」以及「从个性中看到共性、从相对中找到绝对、从暂时中发现永恒」。
「量子纠缠是精神现象」「微观领域里实在性不存在了」——错。科学改变的是我们对物质具体结构的认识，不是物质的客观实在性。

3. 运动、静止、时间、空间

三个头衔一定要分清
  • 运动：物质的根本属性和存在方式；
  • 客观实在性：物质的唯一特性；
  • 时间、空间：运动着的物质的基本存在形式。时间＝持续性、顺序性，一维；空间＝广延性、伸张性，三维。
运动与静止：运动是绝对的、无条件的；静止是相对的、有条件的，是运动的特殊状态，也是运动的量度。「动中有静、静中有动」。
坐高铁时你「静止」地坐在座位上——相对车厢是静止，相对地面在飞驰。静止只是换了参照系的运动；没有「绝对的静」，但也不能否认「相对的静」（否则就是诡辩论）。
两句口诀：运动没主人 ＝ 唯心主义（柏格森「只有动作没有事物」）；物质不动弹 ＝ 形而上学。
时空：客观性是绝对的，具体特性是相对的（相对论里尺缩钟慢，改变的是具体特性）。
「具体物质形态的时空是无限的」错——具体事物的时空是有限的，只有整个物质世界的时空才是无限的。「时空是物质的根本属性」错——根本属性是运动。

4. 实践与世界的二重分化

考点骨架：人类的出现，特别是实践活动，使世界发生二重分化：从自然界分化出人类社会，从客观世界分化出主观世界。实践是这两种分化的关键，也是它们相统一的关键。
实践是人类社会的存在方式；社会生活在本质上是实践的。
自然界与人类社会的区别：自然界里一切都是自发产生的；人类社会里一切都打着人的意识的印记。二者不是截然分开，而是交叉重叠、相互作用——自然界中有「人化自然」，人类社会中也有自然物质和自然力的运用。
「人类社会属于主观世界」错——人类社会是客观物质世界的一部分。「世界上的一切联系都具有人化特点」错——还有大量自在的自然联系。
这里的「实践」是第 2 章的主角。第 2 章会把实践讲成「认识的来源、动力、目的和检验标准」，本章只记住它是二重分化与统一的关键。

5. 物质与意识

意识的起源：自然起源——三阶段（一切物质的反应特性 → 低等生物的刺激感应性 → 高等动物的感觉和心理 → 人的意识）；社会起源——劳动和语言。
意识的本质：意识是人脑的机能和属性，是客观世界的主观映象。人脑是意识的器官，不是意识的源泉（源泉是客观世界）。
意识像一张手机照片：拍的东西（内容）是客观的，但用哪部手机、什么滤镜、什么角度（形式）是主观的。所以同一张双关图，有人看到老太太、有人看到少女；鲁迅说鬼神画来画去也不过是「三只眼、长脖子」——再离谱的想象，原料也来自客观世界。
意识的能动作用四条（多选整组考）：① 目的性和计划性；② 创造性；③ 指导实践改造客观世界；④ 调控人的行为和生理活动（最易漏）。
主观能动性与客观规律性的统一：尊重客观规律是正确发挥主观能动性的前提；从实际出发是前提，实践是根本途径，还要依赖一定的物质条件和物质手段。
人工智能题通杀口诀（近年 1000 题和真题都爱出）：
✅ AI 能模拟、扩展人脑的部分功能；AI 是人的意识能动性的特殊表现，是人的本质力量的对象化。
❌ AI「独立推动认识」「取代 / 超越人类智能」「真正具备意识 / 社会属性 / 情感」「成为实践主体」「意识可以脱离人脑」。
「意识是一切物质的固有属性」错——意识只是人脑的属性。「建筑师在头脑中先建成房子，说明意识先于物质」错——那只说明人的活动有目的性，观念里的房子原料仍来自客观世界。
分析题框架：物质与意识的辩证关系
① 物质决定意识：意识是物质世界长期发展的产物，是人脑的机能，是客观世界的主观映象。② 意识对物质具有能动的反作用：目的计划性、创造性、指导实践改造世界、调控生理活动。③ 正确发挥主观能动性要以尊重客观规律为前提：从实际出发、依靠实践、依赖物质条件。④ 落到材料：××做法既尊重了……的客观实际，又充分发挥了……的主观能动性。

6. 世界的物质统一性

世界的真正统一性在于它的物质性。世界物质统一性原理是辩证唯物主义最基本、最核心的观点，是马克思主义的基石。
三层含义：世界是统一的（一元论）· 统一于物质 · 物质世界是多样性的统一。
实际意义：一切从实际出发，实事求是（党的思想路线的哲学基础）。
「核心」两个字是陷阱重灾区：世界物质统一性原理＝辩证唯物主义最基本最核心的观点；对立统一规律＝唯物辩证法的实质和核心；剩余价值理论＝马克思经济学说的基石；「资本主义必然灭亡、社会主义必然胜利」＝科学社会主义的核心命题。主语不同，各管各的。

7. 联系与发展

联系的四个特点：客观性 · 普遍性 · 多样性 · 条件性。
  • 客观性：联系是事物本身固有的，不以人的意志为转移；人可以根据事物固有联系建立新的具体联系（如修桥、产业链）。
  • 普遍性：任何事物内部各要素相互联系；任何事物都与周围事物相互联系；整个世界是相互联系的统一整体。事物通过中介联系。
  • 多样性：内部 / 外部、直接 / 间接、必然 / 偶然、本质 / 非本质联系。
  • 条件性：条件对事物发展有支持或制约作用；条件可以改变和创造，但不能任意。
迷信、臆造的联系（喜鹊报喜、黑猫倒霉、生肖相冲）→ 选客观性。「借牧」「消费券带动上下游」把不相干的事物串起来 → 选中介 / 普遍性。
系统观念（近年时政化重点）：系统＝相互联系的要素组成的有机整体；结构决定功能，要素结构优化 → 整体功能放大（「串珠成链」「治流域而不是就湖治湖」）。
发展的实质：新事物的产生和旧事物的灭亡。新旧之分看是否合乎历史前进方向、有无远大前途，不看出现时间、形式、一时力量大小。
「新事物」不是「新出厂的东西」。刚上市的传销模式是旧事物，一百多年前提出的科学社会主义是新事物——新旧看方向，不看生日。
「任何事物之间都有直接联系」错（很多是间接的）；「事物之间的联系只有通过人才能实现」错；「人可以任意创造联系 / 条件」错。

8. 对立统一规律（重中之重）

对立统一规律是唯物辩证法的实质和核心：揭示了事物普遍联系的根本内容和变化发展的内在动力；是贯穿量变质变、否定之否定规律以及其他范畴的中心线索；矛盾分析方法是认识事物的根本方法。
同一性与斗争性
  • 同一性：对立面相互依存、相互贯通（相互渗透、在一定条件下相互转化）。
  • 斗争性：对立面相互排斥、相互分离。
  • 关系：同一性是相对的、有条件的；斗争性是绝对的、无条件的。二者相互联结、相辅相成。
同一性的作用：① 是事物存在和发展的前提；② 使矛盾双方相互吸取有利因素而发展；③ 规定事物发展的基本趋势。
斗争性的作用：推动矛盾双方力量此消彼长，促成质变。
夫妻吵架：斗争性是吵（时时都有，绝对的），同一性是「还是一家人」（有条件的——离婚了就没了）。家能存在靠同一性，日子能「质变」（比如决定搬家、换工作）靠斗争把问题推到台面上。
口诀：同一性管「存在」，斗争性管「突破」。选项写「斗争性是事物存在和发展的前提」→ 秒排。
看到「相互依存 / 互为条件 / 相互转化 / 化害为利 / 废物变宝」→ 同一性。
普遍性与特殊性（共性与个性、一般与个别——三个名字一对关系）：矛盾的普遍性寓于特殊性之中；二者在一定条件下相互转化（先试点再推广）。矛盾的特殊性和普遍性的关系问题是关于事物矛盾问题的精髓，是马克思主义基本原理同各国具体实际相结合的哲学基础。具体问题具体分析是马克思主义活的灵魂。
主要矛盾与次要矛盾、矛盾的主要方面与次要方面：主要矛盾决定事物发展的进程；矛盾的主要方面决定事物的性质。→ 两点论与重点论相统一（「弹钢琴」＝两点论，「牵牛鼻子」＝重点论）。
内因与外因：内因是变化的根据，外因是变化的条件，外因通过内因起作用（温度能让鸡蛋孵出小鸡，不能让石头孵出小鸡）。
「矛盾双方融合成新事物是解决矛盾的唯一形式」错——解决矛盾形式多样。「同一性在事物发展中始终处于主要方面」错。「白马非马」割裂的是一般与个别，不是整体与部分。
分析题框架：矛盾分析法（34 题最高频）
① 矛盾是对立统一，同一性和斗争性推动事物发展 → 要在对立中把握统一、在统一中把握对立。② 矛盾具有普遍性和特殊性 → 具体问题具体分析，因地制宜。③ 矛盾发展不平衡（主次矛盾、主次方面）→ 两点论与重点论统一，抓重点、牵牛鼻子。④ 落到材料：××的做法正是……的体现。

9. 量变质变规律

三个概念：质＝事物区别于其他事物的内在规定性（质与事物的存在直接同一）；量＝规模、程度、速度等可用数量表示的规定性（量与事物的存在不直接同一）；度＝保持质的稳定性的数量界限，度的两端叫关节点 / 临界点。
量变与质变的关系：量变是质变的必要准备；质变是量变的必然结果；质变体现和巩固量变成果，并为新的量变开辟道路。
第七个饼才吃饱，前六个是「进度条」——量变是质变的必要准备；「十年磨一剑」「一微克行动」都是在攒进度条。
水在 0–100℃ 都是水（度），到 100℃（关节点）变成汽（质变）。
「底线、红线、临界点、过犹不及、掌握火候」→ 度 / 适度原则。
「积跬步至千里、天下大事必作于细、千里之堤溃于蚁穴」→ 量变质变。
谷堆悖论、秃头悖论 → 割裂质和量，不懂度。
底线思维：「凡事从坏处准备，努力争取最好的结果」——守乎其低而得乎其高；备豫不虞，为国常道。
「量和事物的存在是直接同一的」错（直接同一的是质）。「要把事物永远控制在量变范围内」错。「事物发展是直线上升的」错。

10. 否定之否定规律

辩证否定观四句话（多选常整组出）：① 否定是事物的自我否定，是内部矛盾运动的结果；② 否定是事物发展的环节；③ 否定是新旧事物联系的环节；④ 辩证否定的实质是扬弃（既克服又保留）。
否定之否定：肯定 → 否定 → 否定之否定，形成一个周期，第三阶段「仿佛回到出发点」但在更高阶段。发展是前进性与曲折性的统一，呈螺旋式上升 / 波浪式前进。
鸡蛋从外面打破是早餐（被别人否定），从里面打破是小鸡（自我否定）——辩证否定是后一种。
燃素说被推翻，实验数据却被「翻译」成新化学语言留了下来——这就是扬弃：倒洗澡水不倒孩子。
判断「是不是否定之否定」：要有回到起点的味道——团结→批评→团结；实践→认识→再实践；朴素辩证法→形而上学→唯物辩证法；原始公有→私有→共产主义公有。奴隶→封建→资本主义只是一路更替，没有「回复」，不算。
形而上学否定观：「是就是，不是就不是」——只有克服没有保留，肯定一切或否定一切。「事物内部的否定方面始终处于支配地位」错——平时肯定方面占支配地位。「发展是周而复始的循环」错。
分析题框架：辩证否定观（对待传统文化 / 外来文化 / 改革）
① 辩证否定是自我否定、发展环节、联系环节，实质是扬弃。② 要求对事物采取科学分析态度，反对肯定一切或否定一切。③ 落到材料：对传统文化要创造性转化、创新性发展；对外来文化不照搬也不排斥，批判吸收。

11. 五对基本范畴

范畴关系要点秒杀信号
内容与形式内容决定形式，形式反作用于内容；同一内容可有多种形式，同一形式可表现不同内容反对形式主义、旧瓶装新酒
本质与现象本质决定现象、现象表现本质；现象有真象（正面表现）和假象（反面歪曲表现），假象≠错觉泡沫与深流、透过现象看本质
原因与结果先因后果；一因多果、一果多因；可相互转化连锁反应、蝴蝶效应
必然与偶然二者产生原因、表现形式、地位不同；必然通过偶然开辟道路，偶然背后有必然「偶然是化了妆的必然」
可能与现实可能 vs 不可能＝有无根据和条件；可能 → 现实＝条件是否充分；合乎必然性的迟早变现实嫦娥奔月、水中捞月
筷子插进水里「折了」是假象（客观的，谁看都折）；把熟人认错是错觉（主观的）。
「水中捞月」没有根据 → 不可能；「明年考上研」有根据但条件还不充分 → 可能。
「假象不表现本质」错（假象也表现本质，只是歪曲地）；「本质可以离开现象」错；「偶然不存在」错；「充分发挥主观能动性能把不可能变成可能」错。

12. 辩证思维方法与思维能力

辩证思维方法：归纳与演绎（个别↔一般，最常见的推理形式）· 分析与综合 · 抽象与具体 · 逻辑与历史相统一。
唯物辩证法本质上是批判的、革命的：在对现存事物的肯定理解中包含否定理解，从暂时性方面理解一切既成形式。
主观辩证法与客观辩证法：主观辩证法是客观辩证法在思维中的反映；二者本质上统一，表现形式不同。
七种思维能力（时政化出题的「壳」）：战略思维 · 历史思维 · 辩证思维 · 系统思维 · 创新思维 · 法治思维 · 底线思维。
「以史为鉴、古为今用」→ 历史思维；「不谋全局者不足谋一域」→ 系统 / 战略思维；「从坏处准备，争取最好结果」→ 底线思维。
「系统观念」到习概「新发展理念 / 中国式现代化」还会以「坚持系统观念」的身份再出现——哲学原理是选择题的万能壳，政治五科里的时政材料最后都要落到这几条原理上。
