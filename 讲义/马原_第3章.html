人类社会及其发展规律

这一章是唯物史观（历史唯物主义）：用唯物主义解释社会和历史。选择题考点密、概念对（生产力/生产关系、经济基础/上层建筑、社会存在/社会意识）多，最怕张冠李戴。1000 题本章 56 题（单选 26 ＋ 多选 30）。

先搭骨架：一栋楼的比喻

把一个社会想成一栋楼：
地基里埋着的是生产力（人用工具改造自然的能力）——它决定能盖几层；
一楼是生产关系（谁占有生产资料、怎么分配），生产关系的总和叫经济基础；
楼上是上层建筑：政治楼层（国家、法庭、军队、政党）和观念楼层（法律思想、道德、宗教、艺术、哲学）。
规律只有一句话：下面决定上面，上面反作用于下面。地基一变（生产力发展），一楼迟早要翻修（生产关系变革），楼上也得跟着改（上层建筑变革）——这叫社会形态更替。

1唯物史观与唯心史观

社会历史观的基本问题：社会存在和社会意识的关系问题。
主张社会存在决定社会意识 → 唯物史观；主张社会意识决定社会存在 → 唯心史观。这是二者的根本分野。
唯心史观的两个根本缺陷：① 至多只考察了人们活动的思想动机，没有探究思想动机背后的物质原因；② 否认人民群众是历史的创造者（英雄史观）。
马克思主义哲学创立之后，才开始出现唯物史观与唯心史观的对立；而唯物论与唯心论、辩证法与形而上学、可知论与不可知论的对立古已有之。
唯物史观的创立：马克思、恩格斯发现了人类社会发展的一般规律，使社会历史领域第一次有了科学的理论（《德意志意识形态》首次系统阐述）。

2社会存在：三要素

社会存在＝社会物质生活条件，包括三方面：
要素地位作用
自然地理环境社会生存发展永恒的、必要的条件，生活和生产的自然基础提供生活资料和生产资料来源；影响生产布局、产业结构；作用随生产力水平而变化
人口因素重要的社会物质生活条件数量、质量、结构对生产发展和社会进步起加速或延缓作用；受生产状况和社会制度制约
物质生产方式社会存在和发展的基础及决定力量决定社会的结构、性质和面貌，决定社会形态的更替；是人类其他一切活动的首要前提
这三个头衔是选择题的掉包重灾区，一句口诀：环境「永恒必要」、人口「加速延缓」、生产方式「基础决定」。
选项把「基础及决定力量」安给人口或自然环境 → 秒排。
人与自然的关系：人在自然面前是能动的、积极的，但不能脱离自然规律；应合理调节人与自然之间的物质变换；保护自然与人的发展不是根本对立的（绿水青山就是金山银山）；人对自然的伤害最终会伤及人类自身。
「人类只能适应自然而不能改变自然」「人类已成为自然界真正的主人」「人类任何实践都会伤害自然」「保护生态是人类其他一切活动的首要前提」——全错（首要前提是物质生产活动）。
分析题框架：人与自然的关系（生态文明类材料）
① 自然地理环境是社会存在发展永恒的、必要的条件。② 人与自然是生命共同体，人的能动作用不能脱离自然规律，否则会遭到报复。③ 要合理调节人与自然之间的物质变换，保护生态与发展经济不是根本对立的。④ 落到材料：××做法尊重自然、顺应自然、保护自然，实现了生态效益与经济效益的统一。

3社会意识及其相对独立性

社会意识：社会生活的精神方面，是社会存在的反映。
  • 按主体分：个人意识、群体意识；按层次分：社会心理（低层次、自发）与社会意识形式（高层次、自觉）。
  • 社会意识形式又分：意识形态（政治法律思想、道德、艺术、宗教、哲学等，反映阶级利益）与非意识形态（自然科学、语言学、形式逻辑等）。
社会存在决定社会意识：社会存在是社会意识内容的客观来源；社会意识是社会物质生活过程及其条件的主观反映；随着社会存在的发展，社会意识也相应地或迟或早地发生变化。社会意识变化发展的根源总是深藏于经济事实当中。
社会意识的相对独立性（四个表现，多选常全选）
  1. 与社会存在发展不完全同步：可能落后（旧思想残余），也可能超前（科学预见）；
  2. 与社会经济发展水平不平衡：「经济上落后的国家在哲学上仍然能够演奏第一提琴」（18 世纪法国对英国、19 世纪德国对英法）；
  3. 各种形式之间相互影响，各自具有历史继承性（语言、俗语、节日代代相传）；
  4. 对社会存在有能动的反作用（先进意识促进、落后意识阻碍）——这是相对独立性的突出表现。
「一个时代有一个时代的文艺」「《新华字典》收入新词」→ 社会存在决定意识（依赖性 / 客观来源）。
「没见过猪跑也懂这句俗语」「经济落后但哲学繁荣」「旧观念残留」→ 相对独立性。
「社会意识总是落后于社会存在」「总是起积极作用」「总是消极被动受制于存在」「社会意识不再依赖社会存在」「随时间自主变化」——全错。

4生产力与生产关系

生产力：人类在生产实践中形成的改造和影响自然以使其适合社会需要的物质力量。三个实体性要素：
  • 劳动资料（其中最重要的是生产工具——区分社会经济时代的客观依据 / 物质标志）；
  • 劳动对象（一切自然物质是可能的劳动对象，引入生产的才是现实的；数据已成为新型劳动对象）；
  • 劳动者（生产力中最活跃的因素；现代生产中脑力劳动者日益具有决定意义，高新领域脑力与体力劳动有直接同一的趋势）。
科学技术：渗透在各要素中，是先进生产力的集中体现和主要标志，是第一生产力。
新质生产力：创新起主导作用，以劳动者、劳动资料、劳动对象及其优化组合的跃升为基本内涵，以全要素生产率大幅提升为核心标志。
生产关系：人们在物质生产中结成的经济关系，包括生产资料所有制关系、生产中人与人的关系、产品分配关系。生产资料所有制关系是最基本、具有决定意义的方面，是区分不同生产方式、判定社会经济结构性质的客观依据。
二者关系：生产力是生产的物质内容，生产关系是生产的社会形式，二者统一构成生产方式。生产力决定生产关系（性质、变革）；生产关系反作用于生产力（适合则推动，不适合则阻碍）。
生产关系一定要适合生产力状况的规律，是人类社会发展的普遍规律。
「手推磨产生的是封建主的社会，蒸汽磨产生的是工业资本家的社会」——工具一换，人和人的关系就跟着换。改革开放、深化改革打通新质生产力的堵点卡点，都是在「翻修一楼」让它适合地基。
三个「依据」别混：区分社会经济时代 → 生产工具；区分不同生产方式 / 经济结构性质 → 生产资料所有制；衡量社会进步的根本尺度 → 生产力。
「科学技术是生产力中最活跃的因素」错（是劳动者）；「生产力与生产关系共同组成生产的社会形式」错；「脑力劳动与体力劳动相互独立」错。

5经济基础与上层建筑

经济基础：一定社会中占统治地位的生产关系的各个方面的总和。
上层建筑：建立在经济基础之上的意识形态以及相应的制度、组织和设施。
类型包括
政治上层建筑（居主导地位）国家（核心是国家政权）、军队、警察、法庭、监狱、政府机构、政党、社会集团
观念上层建筑政治法律思想、道德、宗教、艺术、哲学
不属于上层建筑语言、自然科学、形式逻辑（非意识形态）
二者关系：经济基础决定上层建筑（性质、变革方向——经济基础的变更必然引起上层建筑的变革）；上层建筑反作用于经济基础（集中表现为为经济基础服务）。上层建筑一定要适合经济基础状况。
国家：不是从来就有的（历史范畴）；是阶级矛盾不可调和的产物；实质是一个阶级统治另一个阶级的工具；职能有政治统治和社会管理。
「上层建筑只要为自己的经济基础服务就是进步力量」错——要看它服务的经济基础本身是否适合生产力发展。「政治法律制度的先进性是衡量社会进步的根本尺度」错——根本尺度是生产力。「政党属于观念上层建筑」错。

6社会形态的更替

社会形态：经济形态、政治形态、意识形态的具体的历史的统一。
「社会形态发展是自然历史过程」（马克思）——指它是客观的、有规律的过程，不以人的意志为转移；但不是说与人的活动无关、也不是自发的。
社会的发展和进步集中表现为社会形态的更替。
更替的统一性与多样性
  • 统一性（决定性）：社会形态更替归根结底是社会基本矛盾运动的结果，其中生产力的发展具有最终的决定意义；总趋势确定不移。
  • 多样性（选择性）：各国历史条件不同，具体道路多种多样（资本主义有「衰亡、解体、崩溃」三条产生道路；中国跨越资本主义「卡夫丁峡谷」）；但跨越是有条件的，不是随意的。
  • 人们在顺应历史必然性的前提下能够作出自己的选择——规律的客观性并不否定人的能动性。
所有人都要从小学读到大学（统一性），但走哪条路——体育特长生、竞赛保送、普通高考（多样性）——各有不同；「跳级」可以，但得有条件，不能想跳就跳。中国式现代化打破「现代化＝西方化」，就是多样性。
「判断一个变革时代必须以该时代的意识为依据」错（马克思：不能以它的意识为根据，要从物质生活矛盾中解释）；「社会形态跨越是随意的」「制度更替会随生产力发展自发实现」错。

7社会发展的动力

动力头衔
社会基本矛盾（生产力与生产关系、经济基础与上层建筑的矛盾）社会发展的根本动力；其中生产力是最基本的动力因素、最终决定力量
社会主要矛盾一定阶段起主导作用的矛盾，是基本矛盾的具体体现
阶级斗争阶级社会发展的直接动力；社会革命是「历史的火车头」
改革同一社会形态内的量变和部分质变，社会发展的又一重要动力
科学技术推动经济和社会发展的强大杠杆（「伟大的历史杠杆」）：深刻影响生产方式、生活方式、思维方式；是一把双刃剑
文化推动社会发展的重要力量：提供思想指引、精神动力、凝聚力量
「根本」只给社会基本矛盾；「直接」只给阶级斗争；「又一重要」给改革；「杠杆」给科技；「重要力量」给文化。选项里写「科技 / 文化 / 改革是根本动力」→ 秒排。
「文化作为精神力量能直接转化为物质成果」错——要通过实践这个中介；「精神文化条件对人民创造历史起首要的、决定性影响」错——起首要决定性影响的是经济条件。

8交往、世界历史与文明

交往：唯物史观的重要范畴，是人类实践活动的重要组成部分。作用：促进生产力发展 · 社会关系进步 · 文化发展与传播 · 人的全面发展。
世界历史：各民族、国家通过普遍交往，打破孤立隔绝状态，进入相互依存的世界整体化历史。基础是生产方式的发展变革；基本特征是普遍交往；为共产主义的实现提供了条件和路径。
文明：人类创造的物质成果、精神成果和制度成果的总和，是标志社会进步程度的范畴，反映人类社会实践活动的积极成果。文明具有多样性：每种文明都植根于特定环境、体现独特生活方式，都是人类文明的组成部分。
「没有矛盾的和谐世界是世界历史的最终方向」错——和谐是矛盾的一种特殊表现形式，不是没有矛盾。
「世界历史」「普遍交往」到第 5 章「经济全球化」、习概「构建人类命运共同体」还会出现，是选择题的时政接口。

9人的本质与人的发展

人的本质，在其现实性上，是一切社会关系的总和。人的本质属性是社会属性。
含义：人的本质不是单个人天生就有的，也不是从个体身上抽象出的共同性，而是由社会关系决定、随社会关系变化而变化的。
现实的人：基于自身需要和社会需要从事实践活动的、处于一定社会关系中的、具有能动性（也受客观条件制约）的人——不是生物学意义上的人。
人的发展：体力、智力、个性、交往能力的发展，其中最根本的是人的自由程度的提高。三阶段： 人的依赖关系占统治地位（前资本主义）→ 以物的依赖为基础的人的独立性（资本主义）→ 自由个性（共产主义）。
「我是谁」不由 DNA 决定，而由你所处的关系决定：在家是子女、在校是学生、在单位是员工——关系换了，你也跟着变。这就是「一切社会关系的总和」。

10人民群众与历史人物

人民群众是历史的创造者：是社会物质财富的创造者、精神财富的创造者、社会变革的决定力量。
人民群众的总体意愿和行动代表历史发展方向，人民群众的社会实践最终决定历史发展的结局。
人民群众创造历史要受社会历史条件制约：经济条件起首要的、决定性作用，政治条件、精神文化条件也有重要影响。
历史规律的特点：自然规律通过盲目的力量起作用；历史规律只有通过人的有目的、有意识的活动才能实现。「历史是无数个追求自己目的的人的活动的合力」（恩格斯），结果往往不是任何人预期的。人们「不是在自己选定的条件下」创造历史。
历史人物：有时能决定个别历史事件的结局，但不能改变历史发展的基本方向；作用的性质取决于是否符合规律和人民利益；受所属阶级制约；同一人物不同时期作用可能不同；历史人物的出现是必然性与偶然性的统一（「没有拿破仑也会有别人」）。
群众路线：一切为了群众、一切依靠群众，从群众中来、到群众中去——是党的生命线和根本工作路线。
「每个人都是历史的创造者」「人人创造历史」错——创造者是人民群众这个整体；「杰出人物可以改变历史基本方向」「杰出人物无法影响社会进程」两头都错；「剥削阶级代表任何条件下都是反动的」错。
分析题框架：人民群众创造历史（以人民为中心类材料）
① 人民群众是物质财富、精神财富的创造者，是社会变革的决定力量。② 人民群众的意愿代表历史方向，实践决定历史结局。③ 要坚持群众观点和群众路线，坚持以人民为中心。④ 落到材料：××做法问需于民、问计于民，体现了……
