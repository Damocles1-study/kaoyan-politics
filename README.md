## 三个主题（2026-11-01）

**阅读面板**：右下角浮钮（有 ≥4 节的页是「☰ 目录」，其余页是小圆钮；顶部「🎨 主题」打开的也是它）里放目录（亮当前节）、主题、背景色、学习时长，面板开着可以继续滚动。存本机 `pol_skin_v1`（`{skin, hall, turn, still, tint}`），不影响做题记录。

**背景色**（漫画、笔记各存一份，画展不用）：`tint` 0–100，0＝样式表原样（「标准」档），另有米黄 30 / 杏黄 60 / 羊皮 100 三档和滑杆。终点值在 `skin.js` 的 `TINT` 表，按比例插值写到 `html` 行内变量，文字和六色同步压深保住对比度；样式表改了纸面色不用改这张表（起点运行时读）。

`assets/skin.js` 在 `<head>` 同步执行定主题，样式全在 `assets/skin.css`。

- **日式漫画**（默认）：就是 `style.css` 本身，`skin.css` 不碰它。
- **手绘笔记** `html[data-skin="notes"]`：方格本、胶带、荧光笔、红蓝笔批注；系统深色时是黑板。字体运行时取霞鹜文楷（jsDelivr）和 Long Cang、Caveat（Google Fonts），取不到退回系统楷体。
- **艺术画展** `html[data-skin="gallery"]`：整页站在一幅流动的画里，分星夜厅 `data-hall="vg"`（永远夜色）和金箔厅 `data-hall="mu"`（奶油与金，系统深色时转暗）。默认首页、题库、秒杀走星夜，讲义、背诵、大题走金箔；面板里可锁定展厅、换一幅、在「流动 / 静帧」间切换（存 `still`）。场景在 `assets/gallery.js`，只有进画展才加载：
  - **画面**（WebGL2）：笔触顺着自身纹理流动、油彩随鼠标受光、星光呼吸、星夜厅水面倒影、金箔厅金箔反光、溶解换画。没有 WebGL2 时退回静态图（`data-gx-static`），减弱动效或静帧时只画一帧；读书不动时降到约 25 帧。
  - **联动**：滚动推镜并把背景退到焦外；读到新一节镜头换位（停靠点是 `skin.js` 里 `ART` 的 `f`）；左边星图导航；首页悬停模块换背景（`gallery.js` 的 `MOD`）；判题时光线回应；跨页是螺旋仪飞到中央、光圈合拢再打开。
  - **模块**：没有方框，内容铺在羽化的光晕（`--veil`）上。必背＝题刻 · 潜台词＝竖排旁注 · 陷阱＝缺角铭牌 · 串联＝星线 · 比方＝拱窗 · 秒杀＝星芒 · 背诵框架＝卷轴框 · 首页模块＝错落悬挂的小画 · 选项＝图录条目 · 题号＝星点 · 背诵卡＝塔罗牌。

**新页面**：在 `style.css` 那行下面加 `<link rel="stylesheet" href="…assets/skin.css?v=N">` 和 `<script src="…assets/skin.js?v=N"></script>`；改这两个文件要提 `?v=`，改 `gallery.js`、`study_time.js` 要提 `skin.js` 里的 `VER`。**六色关键词的含义不能变**；页面里新写的硬投影用 `var(--drop)`，新写的深色标签要在 `skin.css` 两个主题各加一条；夹在 `.wrap` 直接子级的新散件要加进画展的光晕选择器，否则字会直接压在画上。
**展品**：`_build/tools/build_skin_art.py` 出小图（模块小画、手机背景），`build_skin_hd.py` 出 `art/hd/` 的 1920px 版（WebGL 材质，共约 5.7MB，每页只加载用到的一两张），都是维基共享资源的公有领域原作（来源见 `art/CREDITS.md`）；小矢量由 `build_skin_svg.py` 生成。
**验收**：后台窗格里动画会停在第 0 帧，量几何和截图前先 `document.getAnimations().forEach(a=>a.finish())`，否则会假报横滚、截图发白。

## 写一章的固定流程（续做照这个来）

1. `python3 _build/tools/dump.py <科> <章>` 通读本章全部选择题（紧凑格式）。
2. 写 `_build/notes/<科>_ch<N>.json` 逐题秒杀笔记（键＝题 id，值可含 HTML 与六色类名）。
3. 写 `讲义/<科>_第N章.html`：每节 `<section class="card" id="dN">`，节末 `<div class="qlinks">` 里用 `qlink` 写「单选 9–11」「多选 3–4、9」——**构建脚本据此把「本题知识点」反向登记到每道题**；末节放 `table.onepage` 一页纸（自动进背诵卡）。
4. 在 `build_data.py` 的 `LECT_ALL()` 登记该章 → 重建 → 检查「no lk / no note」都为空、笔记与答案字母零冲突 → 375px 实测 → commit＋push。

## 重建题库

```bash
python3 _build/tools/build_data.py
```

- **题库文字订正**（2026-10-26）：`_build/notes/text_fix.json`＝逐题 `[字段, 原文, 改为]`（字段 stem / A–D），在 `fix()`+`tail()` 之后套用，原文找不到会打印 `TEXTFIX MISS`。来源是三方比对：**PDF 文字层 × 本机 Vision 识别 × 原书页图**——文字层本身也有 OCR 错（「宜传」「戏盲说」「政治安全足国家安全」都是文字层的错），两路识别不一致的地方才回页图定夺。修不了 / 原扫描模糊的题写进 `_build/notes/check_book.json`（`{题id: {q: 题干上方说明, opts: {字母: 说明}}}`），刷题页在题干上方挂说明条、在选项后挂「📖 对照习题本 P..」。
- 输入：`_build/work/questions2.json`（试题）＋ `answers.json`（解析）＋ `_build/notes/manual_fix.json`（人工转录的坏页题）＋ `_build/notes/my_*.json`（⚡秒杀笔记，键＝题 id；马原按章 `my_notes.json`/`my_ch*.json`，其余四科「书上无解析题」先补在 `my_mz/xg/sg/sx.json`，**以后写该科讲义时同 id 的新笔记放进后排序的文件即可覆盖**）＋ `_build/notes/jj.json`（📗 精讲原文，见下）。
- **📗 精讲原文**：1000 题里有 182 道题书上只给「答案＋出处」、没有简析和点拨。`python3 _build/tools/jj_extract.py` 按出处页码和考点号从 `_build/ocr/精讲精练.txt` 截出考点段落（整段只存本地 `_build/work/jj_blocks.json`），再按 `notes/jj_pick.json` 挑句（`{题id: "0,3-5"}` 或 `{题id: {"t": 手写整段}}`，`""`＝段落不对口、不挂）、套 `notes/jj_ocrfix.json` 改识别错，写出 `notes/jj.json`（公开的只有挑出的几句）。挑句时用 `jj_extract.py dump 题id…` 看带编号的句子。**改完 pick 先跑 jj_extract 再跑 build_data。** 中文补丁一律先落成 JSON 文件再用 `merge_notes.py` 合并（heredoc 里写中文会撞编码问题）。
- 从头再来：`ocr_book.py`（本机 Vision OCR，走 `osascript -l JavaScript ocr.js`，Swift 工具链坏了别用 swiftc）→ `dual.py`（试题：版面用 Vision、**文字优先用 PDF 自带文字层**，并学习形近字纠错表 `notes/ocr_fix.json`）→ `parse_q2.py` → `parse_a.py` → `build_data.py`（套用 `ocr_fix.json`＋人工表 `ocr_fix_static.json`）。
- ⚠️ Vision 在这批扫描上常见形近字错：革→草、国→困/图、为→力、党→觉、善→普、事→小/水/班，以及**「具有」→「只有」这种改变题意的错**——只靠生僻字率抓不到，所以试题以文字层为准。
- `_build/ocr/`、`_build/work/` 是整本书的识别文字，**只留本地，不推 GitHub**（.gitignore）。

## 整卷数据（肖八 ＋ 近 3 年真题）

```bash
python3 _build/tools/build_papers.py      # 只改了校对时跑这一句
```

- 源：`政治/教材_去水印/八套卷_试题册.pdf`、`八套卷_解析册.pdf`（`_build/tools/clean.py` 的 `fxwm` 模式：扫描王导出的 PDF 每页＝一张整页扫描图 ＋ 标了 Watermark 的页眉文字 ＋ 个别页一张二维码小图，只保留扫描图那一笔，顺手去掉加密）与 `近3年真题试卷.pdf`。
- **没有文字层，识别靠本机 Vision，而且这套扫描的字体笔画糊，单遍识别每百字错 2–4 个**。所以每本跑三遍：`ocr_book.py`（150dpi）＋ `ocr_multi.py 书 d250` ＋ `ocr_multi.py 书 raw`（直接取扫描原图），再 `ocr_vote.py 书` 按坐标配对、逐字对齐、分歧处用 1000 题＋精讲＋背诵手册的二元字频打分 → `_build/ocr/<书>__vote.txt`。图像增强（灰度 / 锐化 / 放大）试过，没用。
- `parse_papers.py` → `_build/work/papers_raw.json`（肖八）＋ `papers_zt.json`（真题）。题号被装订线吃掉时按「上一题四个选项已齐 ＋ 这一行顶格」补认。**肖八答案两路互证**：逐题「N.答案 X」与每套卷首的答案速查表，8×33 题零冲突。
- **人工校对**：`python3 _build/tools/dump_paper.py 卷 [起 止] [s/o/j/e]` 出通读稿 → 错字写进 `_build/notes/papers_fix/<卷>.json`（`{卷: {题号: {字段: [[原, 改], …] 或 "=整段"}}}`，字段 stem / A–D / jx / ea）→ 重建，`FIX MISS` 要清零。全书反复出现的形近字（人/入、正碗、繁体字）写在 `global.json`，在逐题校对之前套用——**人→入 是带后文判断的正则**（「促进人的」「吸引人才」不能改）。读不准的地方用 `crop_page.py 书 页 上 下 out.png` 截原图看。
- **真题选择题解析**取自《讲真题》解析分册：`parse_papers.parse_jzt()` 按「N. 答案 X 【年份-题号】」标签切出试题简析 ＋ 名师点拨 → `_build/work/jzt.json`，构建时挂到同号真题（`jxsrc` 记页码）。2024–2026 共 84 道有解析（时政题、提法已变的旧题讲真题不收），**讲真题的答案与试卷答案页逐题互证零冲突**。⚠️ 讲真题页眉「第一部分 · 马克思主义基本原理」曾被当成章节标题把解析截断；页边竖排的「马原 / 史纲」单字会混进行首挡住题号；页脚有分销商广告行（「关注公众号…包邮」）——三处都已在 `parse_jzt` 里过滤。
